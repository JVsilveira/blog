# Fontes e decisões verificáveis

Consulta de referência: 21/10/2026. Condições de fornecedores e APIs precisam ser novamente verificadas antes de ativar integrações. Os planos são decisões do projeto, não garantias dos fornecedores.

- React, criação de aplicações: https://react.dev/learn/creating-a-react-app — React admite frameworks com geração estática. Escolhemos Next para manter React em toda UI e HTML público, não por exigência de usar servidor.
- Next, export estático: https://nextjs.org/docs/app/guides/static-exports — a implementação deve verificar restrições atuais, rotas e imagens na versão escolhida.
- Google, JavaScript SEO: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics — pré-renderização facilita acesso ao conteúdo. Não significa garantia de indexação/ranking.
- Google, conteúdo com IA: https://developers.google.com/search/docs/fundamentals/using-gen-ai-content — gerar páginas em escala sem valor não é estratégia editorial.
- Google, requisitos AdSense: https://support.google.com/adsense/answer/9724?hl=pt-BR — conteúdo original e políticas; nenhuma quantidade de artigos neste plano garante aprovação.
- Amazon Brasil, políticas operacionais: https://associados.amazon.com.br/help/operating/policies/ — verificar preço/disponibilidade, imagens, identificação de afiliado, canais e APIs. Padrão do projeto: link “Consultar preço”, sem copiar preço manual de loja.
- Amazon, análise de candidatura: https://associados.amazon.com.br/help/node/topic/G7MJTPEP9NC3YKMG — referência de três vendas qualificadas em 180 dias; reconfirmar antes do cadastro.
- Cloudflare Pages, preços: https://developers.cloudflare.com/pages/functions/pricing/ — arquivos estáticos e funções têm regras distintas; não tratar plano gratuito como servidor ilimitado.
- WCAG 2.2: https://www.w3.org/TR/WCAG22/ — meta de acessibilidade AA, com avaliação real, não selo automático.

Fontes de hardware e celulares são específicas de cada modelo e não foram preenchidas neste planejamento. A etapa de dados deve consultar fabricante e evidências independentes conforme cada afirmação; não existe catálogo verificado entregue neste pacote.

Questões externas pendentes: marca/domínio; contato público; confirmação de produtos usados por João; imagens autorizadas; catálogo inicial; contas de afiliados; eventual aprovação AdSense/CMP; provedor e termos atuais de hospedagem comercial. Essas pendências não impedem desenvolvimento local, mas algumas impedem publicação ou ativação comercial.
